# Дизайн: Эстетичная Kanban-панель с задачами-ссылками и Vim Motions

**Дата:** 2026-11-08  
**Статус:** Утверждён  

---

## 1. Цель и мотивация

Добавить в Truff v2 полноценную эстетичную Kanban-панель поверх чистого Markdown без потери пользовательской разметки, со встроенной привязкой задач к файлам хранилища для мгновенного открытия заметок и полной поддержкой Vim motions для работы без мыши.

Поддерживаются одновременно оба сценария отображения (**A + B**):
- **Режим A (Модальный оверлей `Space b` / `:kanban`):** просторная панель поверх открытой заметки с переключением между всеми досками хранилища (по умолчанию — корневой `kanban.md`).
- **Режим B (Центральная панель `content.rs`):** автоматический рендер файлов `*.kanban.md` и заметок с маркером `<!-- truff:kanban -->` в центральной области вместо сырого текста, с мгновенным переключателем `Board ↔ Source` (`gs` или кнопка в шапке).

## 2. Формат Markdown и владение модулями

### 2.1. Распознавание и структура файла

Файл считается Kanban-доской, если выполняется хотя бы одно условие:
1. Путь заканчивается на `.kanban.md` (или равен `kanban.md` в корне/папке).
2. В первых строках документа присутствует HTML-комментарий `<!-- truff:kanban -->`.

Структура доски в Markdown:
```markdown
<!-- truff:kanban -->
# Проект Truff

## План
- [ ] Спроектировать парсер [[docs/arch|Архитектура]] #core
  Дополнительная строка описания карточки
- [ ] Настроить горячие клавиши

## В работе
- [/] Реализовать рендеринг колонок [[crates/ui/kanban]] #ui

## Готово
- [x] Согласовать дизайн
```

- `## Заголовок` (H2) определяет колонку.
- Непосредственный элемент списка задач (`- [ ]`, `- [/]`, `- [x]`) под H2 определяет карточку вместе с его отступными строками продолжения/подпунктов.
- Любые блоки вне H2 или между карточками (H1 заголовок, вводный текст, разделители, CRLF-переводы строк) остаются нетронутыми благодаря точечным транзакциям по байтовым диапазонам (`Range<usize>`).

### 2.2. Распределение ответственности по крейтам

- **`crates/core/src/markdown/kanban.rs` (`truff-core`):**
  - Типы `KanbanBoard`, `KanbanColumn`, `KanbanCard`, `KanbanTaskStatus`, `KanbanCardLink`.
  - Функция `is_kanban_document(path: Option<&str>, text: &str) -> bool`.
  - Парсер `KanbanBoard::parse(text: &str) -> KanbanBoard` с точными байтовыми диапазонами колонок, карточек, чекбоксов и заголовков.
  - Извлечение инлайн-ссылок `[[target]]` / `[[target|alias]]` и `#тегов` из текста карточки + формирование чистого отображаемого заголовка карточки без сырых скобок `[[...]]`.
  - Генераторы атомарных `Transaction` (с `UndoGroup::next()`):
    - `plan_add_card` (после/до выбранной карточки или в пустую колонку, а также инициализация дефолтных колонок `План` / `В работе` / `Готово`, если доска пуста);
    - `plan_edit_card_title`;
    - `plan_set_card_status` / `plan_cycle_card_status`;
    - `plan_delete_card`;
    - `plan_move_card_vertical` (`J` / `K` внутри колонки);
    - `plan_move_card_column` (`H` / `L` в соседнюю колонку);
    - `plan_paste_card` (`p` / `P` из yank-регистра доски);
    - `plan_attach_file_link` (добавление или обновление `[[path]]` у карточки);
    - `plan_add_column`, `plan_rename_column`, `plan_move_column`, `plan_delete_empty_column`.
- **`crates/ui/src/native/kanban/` (`truff-ui`):**
  - `mod.rs` — публичный фасад `KanbanPanel` и `KanbanAction`.
  - `state.rs` — `KanbanBoardState` (выбранная колонка/карточка, числовой count-префикс Vim, `pending_g` / `pending_d` / `pending_y`, yank-регистр карточки, inline-редактор карточки/колонки с `[[` автокомплитом, поиск `/`, состояние `Board ↔ Source` для центральных вкладок).
  - `picker.rs` — быстрый встроенный fuzzy-пикер файлов хранилища (по клавише `f`) и мини-селектор при наличии нескольких ссылок в одной карточке.
  - `render.rs` — единый эстетичный рендерер доски (как для модального окна `Space b`, так и для `CentralPanel` в `content.rs`).

## 3. Визуальная эстетика и UX задач-ссылок

Дизайн строится строго на семантических токенах [`Theme`](../../crates/ui/src/theme.rs) (Nord, Obsidian Dark, Light) и векторных примитивах [`icons.rs`](../../crates/ui/src/native/icons.rs):

1. **Шапка доски:**
   - Иконка доски, название активной доски, свитчер досок хранилища (`*.kanban.md` + корневой `kanban.md`) в виде аккуратных вкладок-пилюль, общая сводка прогресса (`выполнено / всего`), строка быстрого фильтра (`/`), кнопка `+ Колонка (A)`, переключатель `Исходник (gs)` (в центральном режиме) или `Закрыть (Esc)` (в оверлее).
2. **Колонки:**
   - Ширина колонки `280..320px`, фон `theme.bg_secondary`, тонкий контур `theme.border_subtle`, скругление `8px`, внутренние отступы `12px`.
   - В заголовке колонки: цветной индикатор статуса/индекса колонки, жирный заголовок, пилюля количества карточек и тонкий (`3px`) прогресс-бар доли закрытых задач в колонке.
   - Автоматический горизонтальный и вертикальный скролл за фокусом клавиатуры.
3. **Карточки задач:**
   - Приподнятые карточки (`theme.bg_elevated` / `theme.bg_canvas`), скругление `6px`.
   - Выбранная карточка подсвечивается рамкой `theme.accent` и вертикальной акцентной полосой `3px` вдоль левого края.
   - Кастомный векторный индикатор статуса: пустой контур для `[ ]`, янтарный полукруг/точка `theme.state_warning` для `[/]`, заполненный чекбокс `theme.state_success` с приглушённым текстом для `[x]`.
   - `#теги` рендерятся компактными цветными бейджами.
4. **Задачи-ссылки на файлы:**
   - Все `[[note]]` / `[[note|alias]]` внутри карточки извлекаются и рендерятся в нижней части карточки как кликабельные чипы с векторной иконкой `Icon::File` и коротким именем файла/алиасом.
   - Клавиша `f` открывает встроенный fuzzy-пикер по всем файлам хранилища (`sidebar_file_paths`) и прикрепляет выбранный файл к карточке (`[[path]]`).
   - Во время inline-ввода/редактирования карточки ввод `[[` показывает живые подсказки файлов хранилища (`Tab` / `Ctrl-n` / `Ctrl-p` для подстановки).
   - `Enter` или `gf` (а также клик мышью по чипу файла) мгновенно открывает целевой файл через `Application::navigate_to_link` (если открыт оверлей `Space b`, он автоматически закрывается, переводя фокус в редактор открытого файла).

## 4. Матрица Vim Motions

| Категория | Клавиши | Поведение |
|---|---|---|
| Навигация по колонкам | `h` / `l`, `←` / `→`, `0` / `$` | Соседняя колонка (с поддержкой count `2l`), первая / последняя колонка |
| Навигация по карточкам | `j` / `k`, `↓` / `↑`, `gg` / `G`, `Ctrl-d` / `Ctrl-u` | Вниз / вверх (с count `3j`), первая / последняя карточка, полстраницы |
| Перемещение карточек | `H` / `L` (`Shift+h/l`), `J` / `K` (`Shift+j/k`) | Перенос карточки в соседнюю колонку / сдвиг выше или ниже внутри колонки |
| Статус задачи | `Space`, `x`, `X` | `Space` / `x` — цикл `[ ] → [/] → [x]`; `X` — сразу `[x]` (или снятие, если уже `[x]`) |
| Создание и правка | `o` / `a`, `O`, `i` / `e` / `c` | Создать карточку ниже / выше, редактировать текст выбранной карточки (`Esc` / `Enter` сохраняет) |
| Буфер карточек | `dd`, `yy`, `p`, `P` | Вырезать карточку, скопировать карточку, вставить карточку ниже / выше в текущую колонку |
| История правок | `u`, `Ctrl-r` | Полноценный Undo / Redo через историю `Buffer` |
| Привязка и открытие файла | `f`, `Enter`, `gf` | `f` — fuzzy-привязка файла к задаче; `Enter` / `gf` — открыть привязанный файл (если ссылок нет, `Enter` открывает редактирование карточки) |
| Управление колонками | `A`, `R`, `<` / `>`, `D` | Добавить колонку, переименовать колонку, сдвинуть колонку влево/вправо, удалить пустую колонку |
| Режимы и поиск | `/`, `Tab` / `Shift-Tab`, `N`, `gs`, `Esc` / `q` | Фильтр карточек, переключение доски в оверлее, новая доска, переключение `Board ↔ Source`, закрытие |

## 5. Поток данных, обработка ошибок и тестирование

1. **Единый путь через `Workspace` / `Buffer`:**
   - В центральном режиме правки применяются к активному `Buffer` через `Shell::apply_transaction` и сохраняются на диск штатным механизмом приложения.
   - В оверлее `Space b` выбранный файл доски (по умолчанию `<vault>/kanban.md`) загружается или открывается в `Workspace::buffers`, правки применяются через `Buffer::apply(tx)` с сохранением истории `Undo/Redo` и записью обновлённого снимка с синхронизацией `fingerprint` (без рассинхрона при одновременном открытии этой же доски во вкладке).
2. **Граничные случаи:**
   - Пустой файл доски: отображается приветственное состояние с кнопкой/хоткеем `o` / `A`, первая добавленная карточка автоматически инициализирует стандартные колонки.
   - Несколько ссылок в одной карточке: `Enter` / `gf` показывает компактный выбор ссылки (`1..9` или `j/k` + `Enter`).
   - CRLF (`\r\n`) и кириллица: все байтовые диапазоны вычисляются по UTF-8 границам исходной строки с сохранением стиля переводов строк документа.
3. **Стратегия проверки:**
   - **Unit-тесты `truff-core` (`crates/core/src/markdown/kanban.rs` + `crates/core/tests/kanban.rs`):** парсинг колонок/карточек/ссылок/тегов, перенос `H/J/K/L`, `dd`/`p`, `plan_attach_file_link`, CRLF, сохранение посторонних блоков Markdown, точность `Undo/Redo`.
   - **Интеграционные тесты `truff-ui` (`crates/ui/tests/kanban_workflows.rs`):** открытие оверлея по `Space b` и `:kanban`, Vim-навигация с count-префиксами, привязка файла через `f`, мгновенное открытие файла по `Enter`/`gf`, рендер `*.kanban.md` в центральной панели и переключение `Board ↔ Source` по `gs`.
